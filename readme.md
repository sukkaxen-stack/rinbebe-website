# For Love - Personal Website

A romantic personal website template. This website is dedicated to compiling memories, letters, photos, music, and videos for someone special.

## Structure

```
ForLove/
├── index.html      # Main HTML file
├── styles.css      # CSS styling
├── script.js       # JavaScript for interactivity
├── images/         # Place your images here
│   ├── hero.jpg        # Main hero image
│   ├── gallery1.jpg    # Gallery image 1
│   ├── gallery2.jpg    # Gallery image 2
│   ├── album.jpg       # Music album cover
│   ├── video-thumb.jpg # Video thumbnail
│   └── author.jpg      # Author profile picture
└── README.md
```

## How to Use

1. **Add Your Images**: Create an `images` folder and add your personal photos:
   - `hero.jpg` - Main banner image
   - `gallery1.jpg`, `gallery2.jpg` - Gallery photos
   - `album.jpg` - Album art for the music player
   - `video-thumb.jpg` - Video section thumbnail
   - `author.jpg` - Profile picture for the author section

2. **Customize Content**: Open `index.html` and edit:
   - The letters content in the Letters section
   - Song name and artist in the Music section
   - Video embed (replace placeholder with actual YouTube embed)
   - Author name and messages

3. **Open the Website**: 
   - Simply open `index.html` in a web browser
   - Or use a local server for best results

## Features

- **Responsive Design**: Works on desktop, tablet, and mobile
- **Smooth Scrolling**: Navigation links scroll smoothly to sections
- **Interactive Elements**: Hover effects, button states
- **Dark Sidebar**: Modern side navigation with scroll indicator
- **Letter Cards**: Categorized letters with tags (love, career, health, etc.)
- **Music Player**: Visual music player component
- **Video Section**: Embedded video placeholder
- **Footer**: Standard footer with links

## Customization

### Colors
Edit the CSS variables in `styles.css` to change the color scheme:
- Tags: `.tag-love`, `.tag-career`, `.tag-health`, `.tag-you`
- Sidebar: `.sidebar` background
- Accent color: Currently green (#4CAF50)

### Fonts
The website uses:
- **Playfair Display** for headings
- **Inter** for body text

You can change these in the Google Fonts link in `index.html`.

## Browser Support

Works in all modern browsers:
- Chrome
- Firefox
